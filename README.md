# 🍁 메이플헬퍼 (MapleHelper)

**재부팅 없이** 윈도우 필터키를 즉시 제어하는 프로그램입니다.

![platform](https://img.shields.io/badge/Windows-10%20%7C%2011-0078d6)

## 다운로드

👉 **[최신 버전 설치 파일 받기](https://github.com/Lsdfajsgd/FilterKey/releases/latest)**

`MapleHelper_x.x.x_x64-setup.exe`를 받아 실행하면 설치됩니다.

> 💡 다운로드 시 "Windows에서 PC를 보호했습니다" 경고가 뜨면
> **추가 정보 → 실행**을 누르면 됩니다. (개인 개발 프로그램에 공통으로 뜨는 경고입니다)

## 기능

- **필터키 ON/OFF** — 상단 스위치 또는 전역 단축키로 즉시 토글 (기본 `Ctrl+Alt+F9`)
- **프리셋** — 사냥/보스 등 상황별 값을 저장하고, 게임 중에도 단축키로 즉시 전환
- **알기 쉬운 한국어 설정** — 슬라이더 + 숫자 입력, ms/초 단위 전환
- **레지스트리 영구 저장** — 켜면 재부팅 후에도 유지, 끄면 이번 세션만
- **비프음 피드백** — 게임 화면에서도 단축키가 적용됐는지 소리로 확인
- **트레이 상주** — 창을 닫아도 백그라운드에서 단축키가 계속 동작

## 사용법

### 1. 값 조절하기
왼쪽 목록에서 **현재 값 (커스텀)** 을 선택하고 슬라이더로 값을 조절한 뒤 **[적용]** 을 누르면
재부팅 없이 바로 반영됩니다.

| 항목 | 의미 | 권장 |
|---|---|---|
| 키가 먹히기까지 시간 | 누르고 나서 입력으로 인정되기까지 | **0** |
| 연타 시작까지 대기시간 | 꾹 눌렀을 때 연타가 시작되기까지 | 초보 150 / 고수 100 |
| 연타 속도 (한 번 간격) | 연타 사이 간격 — 낮을수록 빠름 | 초보 20 / 고수 10 |
| 같은 키 연타 무시 시간 | 뗐다 다시 누를 때 무시되는 시간 (연타 씹힘 주범) | **0** |

각 항목에 마우스를 올리면 자세한 설명이 표시됩니다.

### 2. 프리셋 사용하기
- 왼쪽 목록에서 프리셋을 선택 → 값 수정 → **[저장]** 또는 **[적용]**
- **[+ 프리셋]** 버튼으로 현재 값을 새 프리셋으로 저장
- 프리셋 이름은 상단 제목을 클릭해서 바로 수정
- **단축키** 행에서 프리셋 전환 단축키 지정 — 게임 중에도 동작

기본 제공 프리셋:

| 프리셋 | 단축키 |
|---|---|
| 사냥 | `Ctrl+Alt+F10` |
| 보스 | `Ctrl+Alt+F11` |
| 윈도우 기본값 | - |

### 3. 설정 (⚙ 버튼)
- **ON/OFF 토글 단축키** 변경
- **표시 단위** (ms ↔ 초) 전환
- **레지스트리 영구 저장** / **단축키 동작음** 켜고 끄기

### 4. 종료하기
창을 닫으면 트레이로 최소화되어 단축키가 계속 동작합니다.
완전히 종료하려면 **트레이 아이콘 우클릭 → 종료**.
